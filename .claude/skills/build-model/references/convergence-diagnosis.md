# Convergence diagnosis

Read the observed order and the location of the largest error before deciding
anything. Each row below happened in this repo.

| Symptom | Likely cause | What to do | Seen in |
|---|---|---|---|
| Observed order close to the method's design order (about 2 for second-order FV or quadratic FE) | Healthy, in the asymptotic range | Report GCI and the extrapolated value | channel header (1.95), duct (1.99), cantilever TET10 (2.04) |
| Observed order near 0.5 or lower, metric keeps drifting with refinement | A singularity inside the metric's footprint: velocity jump at a wall corner, re-entrant corner, clamp corner | Move the measurement away from it, model the real geometry (header, fillet), or define the metric on the smooth region. Do not loosen the GCI limit | uniform-inlet channel (0.49) |
| Peak value grows without bound with refinement | Point singularity (stress at a sharp corner) | The peak is not a valid requirement metric; use an extrapolated or linearized value | cantilever von Mises at the clamp corner (150 → 217 MPa) |
| Differences change sign between meshes at a tiny level | Converged to round-off or iterative noise; GCI not applicable | Oscillatory regime: uncertainty = 1.25 × half-range (Stern 2001) | cantilever root stress (~1e-4) |
| Three values agree to a few parts per million but the check says "divergent" | Noise below any meaningful convergence signal; the sign of the ratio is random | The harness now classes a relative spread under 1e-5 as converged (`noise_floor`) | cantilever root stress in the peak-stress test (4e-6) |
| Sign changes with growing amplitude (convergence ratio ≤ −1) | Not converging at all | Classed divergent, no estimate. Refine further or look for a bug | peak stress on a coarse smoke test |
| GCI passes, but the observed order is far above the design order (3.7 for second-order elements) | The three values only look converged: a singularity or a coincidence | No estimate ("anomalous order"); pass `design_order` to `discretization_uncertainty`. Never treat such a pass as evidence | peak von Mises at the clamp corner |
| Observed order about 1.1 for a smooth global quantity (tip displacement, first frequency) with design order 2, while the extrapolated value matches an exact reference to 1e-4 | A clamp meeting a free surface leaves a corner singularity that sets the global rate | Fine: a rate below the design order makes the GCI more conservative, not less. Do not refine further to 'fix' it | Turek-Hron flag CSM1 / CSM2 (1.12; extrapolated 0.008 % from the benchmark); bracket modal TET10 (1.8) |
| A requirement metric passes in a mesh study but nothing checks its convergence | The harness only judged the metrics the study author thought of | Give every requirement metric a convergence check (the cantilever study now does this automatically) | "max von Mises anywhere" requirement |
| Observed order differs widely between nearly identical designs (1.66 vs 1.16) and the GCI swings from 4.5 % to 7.4 % | The feature that carries the metric is not being refined (a curvature-based size or a minimum size held the fillet mesh), and mesh scatter is comparable to the level-to-level change | Check the element size at the peak actually changes between levels; refine locally there. Do not size a design margin from such a study | clevis global studies at c004 and c011 |
| Peak at a fillet jumps by several percent, then wobbles by about +-0.5 % under further local refinement | Under-resolved until the elements are about r/3; after that, the nodal maximum of a tet mesh jitters | Pick the study's levels inside the band, not across the jump (a jump-plus-flat triple reads as anomalous order). Inside the band the three-level ratio is a coin toss (c011 oscillatory, design D 'divergent', R = 4.4, on a 0.99 % spread): measure the mesh-to-mesh scatter independently (near-identical designs at the same mesh settings) and declare it (`mesh_noise_rel`), so a spread under it is classed converged with uncertainty 1.25 x half the spread | clevis c011 and design D, fillet element size 1.5 -> 0.667 mm |
| Maximum error against a reference sits in one cell at a step in a boundary condition and does not shrink (5.5 / 2.8 / 6.3 %), while the error elsewhere converges at second order | A singular point of the boundary data (flux stepping from zero); the reference's assumption fails there too | Measure outside a band of a physical length (2 gap heights) round the step, keep the tolerance; report the band. Do not drop the check | cold plate CFD wall temperature at the plate edges |
| A small, constant offset from an 'exact' reference (1.3e-3) that ignores mesh, penalty and the friction coefficient | A physical effect the reference leaves out, here the interface tilting with the strain (contact on deformed surfaces) | Scale the parameter the suspected effect depends on (E x 10, x 100); if the offset follows it, extrapolate to the limit where the reference is exact and check that, and report the offset as model form | bolted joint slip load vs mu F_V |
| Smooth integral (flux linkage) converges at order 0.19 under global refinement; later at 0.45-0.6 with a GCI near 0.1 % | The coarsest level puts thin features (rotor bridges 1-1.5 mm) under one element, outside the asymptotic range; the saturated bridges keep the rate low | Drop the coarsest level and add a finer one (0.19 became 1.95); a low order with a tiny GCI is conservative, accept it | motor open circuit (fineness 1/2/4, then 2/4/8) |
| Maximum of linearized stress over stress classification lines next to a sharp corner oscillates by about +-1.3 % (430 / 420 / 424 MPa) while the corner peak grows without bound | The lines nearest the corner sample its singular field; the integral converges, the line of the maximum shifts | Accept the oscillatory estimate (1.25 x half-range) and set the GCI limit from the decision's margin before the run (3 % against a 27 % margin); never judge the corner peak | rotor bridge at overspeed |
| A smooth integral changes by under 0.1 % across three meshes but the differences grow (R about 2.2-2.7), so the GCI says "divergent" | Mesh-to-mesh noise from regenerated meshes (Pyleecan rebuilds FEMM's mesh at each fineness) at the 1e-4 level, above the 1e-5 noise floor | Measure the noise at a fixed fineness (small perturbations) and declare it as `mesh_noise_rel` before the rerun; until then the verdict is withheld even when the margin is large | motor back-EMF peak (r1), MTPA torque at 333 A |
| Observed order about 0.8 on a systematic refinement of a smooth integral (friction factor), the coarsest level moving most, GCI 2.6 % | The coarsest level is outside the asymptotic range (axis cell about 7 mm), and the near-wall model (SST's wall omega from the first-cell distance) keeps moving as the wall cell shrinks | Shift the family one level finer (80 / 160 / 320 instead of 40 / 80 / 160), changing nothing else; check that the finest level converges in a probe first. Never quote the middle mesh's agreement with a correlation | pipe friction, k-omega SST, low-Re |
| A coupled-run metric moves away from the benchmark as the fluid mesh refines, with an apparent order of 3.5 and no GCI | The coarsest mesh (+5.8 %) is far outside the asymptotic range, so the three values cannot define a rate | Rule out the other participant cheaply first (a finer solid moved it 0.035 %), then drop the coarsest level and refine by sqrt 2 instead of 2 | Turek-Hron FSI1 uy(A), fluid 5 / 2.5 / 1.25 mm |
| A half-grid interpolation check fails, and every one of its worst nodes is on the row next to a grid edge, while the median error elsewhere is 0.03 % | The tabulated function bends sharply near the edge (saturating bridges at low current), and the coarse half grid spans the bend | Check the output the table feeds (the map from the half table against the full one); refine only the rows near the edge with a supplementary run that repeats one row of the main table | motor dq table, iq 0-50 A |
| A mesh level that converged before now stalls (iterative change 9e-5 after 80000 iterations against 3e-11 after 15000), and the finer level never converges | Something besides the mesh changed between the runs: here the axial length of a periodic wedge, 20 x shorter | Diff the two runs' inputs; revert the change that was not needed and rerun. Do not raise the iteration cap first | pipe friction r1 (axial_length_rule) |
| Convergence ratio R ≥ 1 | Coarse meshes outside the asymptotic range, or a bug | Refine further; if it persists, look for a bug | - |
| Large error that does not shrink steadily and sits in one region | Mesh distribution bug (inverted grading), boundary condition on the wrong face | Print the location of the maximum error; inspect the mesh there | duct with inverted side-wall grading (error always in the first cell from the wall) |
| Integral metric passes but a field check fails | A local error that averages out | Trust the field check; find the region | duct (pressure gradient passed at 40 and 80 cells) |
| Normalised residuals stall around 1e-3 while the result is constant to 10 digits | The field is exactly zero or uniform (cross-flow, cross-section pressure), so the normalisation divides by almost nothing | Judge convergence on the quantity of interest and on the meaningful field's residual; record why in the case | duct p, Uy, Uz |
| Quantity of interest converges slowly and geometrically over thousands of SIMPLE iterations | Pseudo-time diffusion: under-relaxation acts like a time step limited by the smallest cells, and the slow mode spans the largest dimension | Run more iterations; check the change over the last 10 %. Relaxation near 1 diverged; a multigrid velocity solver did not help | duct across a 10 mm half-width with 12 µm cells |
| Clean observed order and a tiny GCI, but the converged value is a few percent off an exact reference | A modelling error that does not shrink with the mesh (the formulation is not what the case assumes) | Run an exact limiting case through the same pipeline before trusting the reference comparison; vary the suspected parameter | strap: CalculiX plane-stress elements on a 4 mm section converged to Kt 3.045 vs Kirsch 3.000 |
| Coarse elements too stiff, error 4-33 % | Locking / low-order elements (linear tets in bending) | Use quadratic elements; keep the linear-element run as evidence | cantilever TET4 |
| Output not on the requested grid | Tool silently ignored the requested settings | Fix how settings are passed; never relax the grid check | OpenModelica `-override` |
| Every numerical check passes but a validity check fails | The model is the wrong tool for this point | Revise the scenario or the model; withhold verdicts | quarter car at 36 km/h (wheel lift) |
